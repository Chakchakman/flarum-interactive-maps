# Token owner prefix search

Owner-requested on 2026-10-24. Separate feature on top of composer-map-attachment; no schema or production dependency changes. The accepted Alpha.7 picker behavior remains.

Both creating a token and assigning an existing token use a controlled username combobox. Type at least three characters; after 250 ms debounce, search the beginning of username (not email/display name). Return at most ten suggestions, case matching following the forum DB collation. Escape/blur closes suggestions, arrow keys and Enter choose an option, and clicking an option fills the exact username. Empty owner means unassigned. Reassignment uses a Flarum modal with explicit Save/Cancel instead of a native prompt. Saving an unknown name or an API failure preserves the prior token assignment and permits retry. The dropdown stays in layout so it does not cover Save/Cancel.

GET /api/chak-map-users?prefix=... requires map.manage on the PHP server before querying any users. Below three characters it returns an empty list; excessive/invalid values are rejected. LIKE wildcards are escaped as literals; only a trailing prefix wildcard is added. User visibility scopes apply. Each resource contains only id/username, without email, credentials or profile extras. Token assignment endpoints continue to independently validate map management and exact username existence. This does not change Flarum's native username registration policy.

Browser checks create disposable confirmed users and a dedicated map/token: lower/upper-case prefix, literal %/_ characters, short queries, bounded results (12 fixture matches -> 10 suggestions), no email fields, guest/member refusal, mouse/keyboard selection, creation, real invalid-username rejection, cancellation, reassignment/reload/unassignment preserving the token, simulated search/save errors and successful retries, and an old delayed response arriving after the current results. The existing player test also requires member search API denial. All five Alpha.7 and two composer scenarios remain part of the regression gate.
